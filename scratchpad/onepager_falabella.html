Qué es CLI Market

Una capa de comercio para agentes de IA: cuando un asistente como Claude necesita saber dónde comprar algo más barato, consulta nuestra API en vez de navegar sitio por sitio. Hoy comparamos Wong, Metro y Plaza Vea en Perú — el catálogo de Falabella es la pieza que falta para dar una comparación completa.

La propuesta — dos partes relacionadas
Técnico

Integración de catálogo

El conector para la API REST de Falabella (Magento/Adobe Commerce) ya está construido y probado contra otros retailers de la misma plataforma. Solo falta un token de acceso de solo lectura al catálogo de falabella.com.pe.

Comercial

Creators F, un caso nuevo

Cada recomendación de un agente de IA que termina en una compra es tráfico con intención real, tan atribuible como el link de un creador de contenido. Nos gustaría explorar si ese tráfico puede sumarse al modelo de Creators F.

Qué necesitamos de Falabella
  • 01
    Un token de API de solo lectura Acceso de catálogo (Magento REST) para falabella.com.pe — sin permisos de escritura ni datos de clientes.
  • 02
    15 minutos con el equipo correcto Partnerships, e-commerce o quien administre Creators F — para validar si el modelo de tráfico por agente encaja en el programa actual o requiere un acuerdo aparte.
